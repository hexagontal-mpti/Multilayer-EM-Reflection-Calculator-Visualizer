# Multilayer-EM-Reflection-Calculator-Visualizer
A Solarus-based Lua script that calculates and plots electromagnetic reflection coefficients (dB) for multi-layered media. Features real-time frequency scrolling and complex impedance transformations.

## Installation
1. Ensure you have the [Solarus Engine](https://www.solarus-games.org) installed.
2. Clone this repository.
3. Start this code.
